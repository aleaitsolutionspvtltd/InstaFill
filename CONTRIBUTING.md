# Contributing to InstaFill

Thank you for your interest in contributing to **InstaFill**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

## Getting Started

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/instafill.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```

## How to Contribute

### Reporting Bugs
- Search existing issues before opening a new one.
- Provide a clear description of the problem and steps to reproduce.
- Include your browser version and environment if relevant.

### Suggesting Improvements
- Create an issue with the proposed change.
- Explain the current behavior and the desired behavior.

### Submitting a Pull Request
- Use a descriptive branch name.
- Keep your changes focused and small.
- Add comments in code where needed.
- Update the documentation if you change user-facing behavior.
- Reference the issue number in your PR description.

## Code Guidelines
- Write clean, readable code.
- Use consistent indentation and formatting.
- Keep logic modular and avoid large functions.
- Add comments for complex behavior.

## Open Source Values
- Be respectful and courteous.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Keep contributions accessible and easy to review.
