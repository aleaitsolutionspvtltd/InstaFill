# ⚡ InstaFill

A professional mock data form-filling extension for developers and QA engineers. Features smart form crawling, regional data profiling, custom field overrides, and automated dependent dropdown (Country ➔ State ➔ City) cascade handling.

---

## 🎯 Features Checklist

### 🧠 Smart Form Detection
- Scans `input` (all types), `textarea`, `select`, `checkbox`, and `radio groups` across same-origin frames.
- Identifies intent based on semantic markers (`id`, `name`, `placeholder`, `autocomplete`, and wrapping labels).
- Enforces strict constraints (such as `maxLength` truncation and numerical bounds).

### 🌍 Regional Identity Profiling
- Generates geographic-consistent identities utilizing **United States (US)** or **India (IN)** profile groupings.
- Automatically pairs first names, last names, emails, street layouts, state codes, cities, and zip codes to avoid mismatch errors.
- Never outputs numbers inside standard alphabet-only name fields.

### ⚙️ User-Defined Custom Overrides
- Configure custom mappings (e.g. override key `zip` to `110001` or `email` to `tester@domain.com`) through the popup window.
- Persisted locally and securely inside Chrome Extension storage.
- Matched utilizing semantic intent and exact selectors/substrings.

### 🔄 6-Phase Dynamic Form Automation Pipeline
- **Phase 1 (Standard Inputs):** Automatically injects standard text, dates, numbers, textareas, checkboxes, and radio buttons instantly.
- **Phase 2 (Country Dropdowns):** Identifies country fields (native `<select>` or custom Radix triggers) and automates selection.
- **Phase 3 (State Cascades):** Polls dynamically for state options to populate (using active AJAX/state update detectors) and automates selection.
- **Phase 4 (City Cascades):** Polls dynamically for city options to populate following state updates, and automates selection.
- **Phase 5 (Generic Comboboxes):** Waits for dynamic framework re-renders to settle, then populates generic controls (Timezone, Language, Currency) with `60ms` spacing to prevent portal overlay collision.
- **Phase 6 (Final Verification Sweep):** A final, proactive validation pass that scans a fresh DOM snapshot. Any reset or dynamic fields are instantly secured and filled with 100% certainty.

### 🔐 Password & Confirm Password Synchronization
- Automatically pre-generates a single, unified password per form-fill run.
- Ensures all matching Password, Confirm Password, and Verify Password fields are identical, passing frontend verification constraints.

### 💾 Global Persistence Vault
- Save form states across multiple domains simultaneously.
- Global accordion-based vault manager built into the extension popup.
- Dynamically edit saved payloads directly from the popup.
- Context-aware UI ensures that state injection is securely restricted to the correct URL.

## 🛠️ Installation & Setup

1. Clone or download the repository:
   ```bash
   git clone https://github.com/aleaitsolutionspvtltd/InstaFill.git
   ```
2. Open your Google Chrome browser and navigate to:
   ```text
   chrome://extensions/
   ```
3. Toggle the **Developer mode** switch in the top right corner to **ON**.
4. Click on the **Load unpacked** button in the top left corner.
5. Select the `dist` folder inside the `InstaFill` directory that was generated by the build process.
6. The extension is now successfully registered and active!
