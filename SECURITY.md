# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in InstaFill, please report it by opening a new issue with the label `security`.

Do not include exploit details in the issue title or description if the vulnerability is sensitive. Instead, contact the maintainers privately if possible.

## Supported Versions
We actively maintain the current release and the previous release. Security fixes may be backported to earlier versions at the maintainer's discretion.

## Disclosure Policy
Please allow time for maintainers to review and address reported security issues before publicly disclosing them.
