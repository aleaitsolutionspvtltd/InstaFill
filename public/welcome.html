⌨️ Quick Start
Quick Fill Shortcut
Ctrl + Shift + F

Press this combination to auto-fill any form on the current page

🎓 Getting Started
  1. Right-click on any form to access InstaFill options
  2. Use the popup icon to quickly access features
  3. Visit Options to customize your settings
  4. Press Ctrl+Shift+F to auto-fill forms instantly
